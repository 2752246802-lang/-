# 个人电商作品集网站

电商设计师 / AI 设计师个人作品集，使用 React + Vite 构建。

## 本地预览

Windows 下可以直接双击 `启动网站.bat` 或 `一键启动并打开.bat`。

也可以在当前目录打开终端执行：

```bash
npm install
npm run dev
```

启动后打开终端提示的本地地址，通常是 `http://localhost:5173`。

不要直接双击 `index.html`，React + Vite 项目需要通过 Vite 开发服务器运行。

## 当前内容

- 全屏首屏：作品图背景、个人定位、联系方式和数据亮点
- 个人简介：教育背景、工作经历、项目经历和核心能力
- 作品展示：国际站详情页、国际站首页、内贸阿里首页、内贸详情页、AI 辅助设计
- 分类筛选：全部、详情页设计、首页设计、AI 辅助设计
- 响应式布局：桌面端和手机端均可浏览，长图作品支持卡片内滚动预览

## 构建

```bash
npm run build
```

构建产物会输出到 `dist/`。
